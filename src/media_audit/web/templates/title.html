How the averages are worked out
  • Only episode video files count. Subtitles, artwork, .nfo files and extras are left out, so averages can be smaller than size ÷ episodes from the Size column.
  • Specials (Season 0) are left out of the show-wide averages at the top of the page. They're often a different length or quality from the main seasons, so they get their own row instead.
  • A file covering several episodes (e.g. S01E01–E03) counts as that many episodes.
  • Duplicates: when an episode has more than one file (two qualities, or a leftover copy), it still counts as one episode but all its files' sizes count. The average is what each episode costs on disk, so duplicates raise it; seasons with them are marked "with extra copies".{% if ep and ep.dup_episodes %} This show has {{ ep.dup_episodes | num }} such episode{{ "s" if ep.dup_episodes != 1 }} outside specials.{% endif %}
  • GB/h is total size ÷ total running time, so long and short episodes are weighted fairly. Avg length is per file.
