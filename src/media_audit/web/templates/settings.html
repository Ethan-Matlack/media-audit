Paths on the server

Only cleanup scripts use these: they run on the server, not in the container, so they need each folder's path there. Usually there's nothing to add. With one media path in the container, the container's own settings already provide it (on Unraid: the Host media path variable), and it shows below with a 🔒. Add a mapping only for an extra media path you've mounted, e.g. /media/archive from another disk. The longest matching folder wins, so it takes precedence over the one for /media.
